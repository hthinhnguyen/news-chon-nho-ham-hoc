Privacy Policy

Effective date: 24 October 2026 · Applies to the chon-nho-ham-hoc tool ("the tool") operated by Nguyễn Hữu Thịnh.

Uses YouTube API Services

1. YouTube API Services

The tool uses YouTube API Services to upload videos to, and read the status of videos on, the YouTube channel of the person who signs in. By using the tool you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

2. Who uses the tool

The tool is used only by its owner, Nguyễn Hữu Thịnh, to manage the owner's own channel. It is not available to the public. You must agree to this Privacy Policy before using any feature of the tool.

3. Information the tool accesses, collects, stores and uses

OAuth 2.0 access and refresh tokens for the signed-in Google account (scope https://www.googleapis.com/auth/youtube)To upload videos, check their status and delete the tool's own uploads on requestA file on the owner's computer readable only by the owner, until access is revoked

The tool does not collect names, email addresses, comments, subscriber data, analytics or any information about other YouTube users or viewers.

4. How information is used, processed and shared

Information is used only for the purposes listed above. It is processed on the owner's computer and sent only to Google/YouTube through the YouTube Data API. It is not sold, rented or shared with any other internal or external party, and it is not used for advertising.

5. Third-party content and advertising

The tool does not show advertising and does not let third parties serve content or ads through it. (Ads shown by YouTube on the published videos are governed by YouTube.)

6. Cookies and device storage

The tool does not use cookies. It stores the OAuth token file and the local database described above on the owner's own device. This website does not use cookies or analytics.

7. Revoking access and deleting data

You can revoke the tool's access to your Google account at any time via the Google security settings page. The tool also provides a disconnect command (youtube_auth.py --revoke) that revokes the token with Google immediately and deletes the stored token and all stored YouTube API data. After revocation through Google's page, the tool can no longer refresh stored YouTube data, and it is deleted within 30 days. Deletion requests are completed within 7 days.

8. Changes

Changes to this policy are published on this page with a new effective date.
